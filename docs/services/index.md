# Services

Each backend service documented as a **black box**: its responsibilities, its
boundaries, and its formal contracts. Service interfaces are the one place we keep
formal, testable specs — authored in **TypeSpec**, compiled to **OpenAPI** (HTTP)
and paired with **AsyncAPI** (RabbitMQ).

Start a new page from `templates/service.md`.
