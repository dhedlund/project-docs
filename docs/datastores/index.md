# Datastores

The databases and message queues the services depend on (e.g. MySQL, PostgreSQL,
MongoDB, RabbitMQ, Redis). Each page describes what a store holds; its "Used by" is
generated automatically from the services' `depends_on`.

Start a page from `templates/datastore.md`.
